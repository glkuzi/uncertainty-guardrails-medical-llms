# UHead for medical diagnoses

This repository accompanies the EMNLP 2026 paper "Uncertainty Guardrails for LLM-Based Medical Diagnostic Systems" and provides code for training and running UHead.

UHead estimates confidence scores for medical diagnoses generated by a large language model (LLM). This repository also includes code for reproducing the paper's results.


## Quick start

1. Install the project in editable mode using the following command. It depends on the dev branch of LM-Polygraph:

```
pip install -e .
```
2. The notebook [./notebooks/build_medical_data_fix_template.ipynb](./notebooks/build_medical_data_fix_template.ipynb) builds training and evaluation datasets for UHead and Text-based UQ (TB UQ) from logs containing black-box or white-box LLM generations produced by the LM-Polygraph fork [LM-Polygraph](https://github.com/IINemo/lm-polygraph).
3. The [./scripts/med_exps_paper](./scripts/med_exps_paper) directory contains training scripts for UHead, UHead with a proxy model, and TB UQ. The main training entry points are [./train_luh/run_train_luh.py](./train_luh/run_train_luh.py) for UHead and [./train_luh/nli_encoder_train.py](./train_luh/nli_encoder_train.py) for TB UQ.
4. The notebook [./notebooks/prr_extract_results.ipynb](./notebooks/prr_extract_results.ipynb) shows how to extract results and generate the tables and plots used in the paper.

## Inference with a trained UHead

1. Run the following command with the paths to your LLM and trained UHead checkpoints:

```
CUDA_VISIBLE_DEVICES=0 PYTHONPATH=./ python train_luh/basic_usage_claim_flask.py --model_path "PATH_TO_YOUR_LLM_MODEL" --uhead_path "PATH_TO_YOUR_UHEAD_MODEL"
```
Once started, the server listens on http://localhost:5000.

2. Send a POST request to obtain a confidence score for each predicted diagnosis. The example below uses a synthetic medical prompt in Russian:

```
curl -H "Content-Type: application/json" -X POST http://localhost:5000/post -d '{
  "prompts": [
    "Ты врач с большим опытом работы.\nЯ пациент мужского пола. Мне 25 лет. Я обратился к тебе с проблемой.\nНазови 3 самых вероятных потенциальных диагноза, основываясь на диалоге:\n<диалог>\n<врач> На что жалуетесь?\n<пациент> Сильно болит горло, глотать почти невозможно.\n<врач> Как давно началось?\n<пациент> Два дня назад.\n<врач> Температура есть?\n<пациент> Да, вчера была 38.5, сегодня 37.8.\n<врач> Что-то еще беспокоит, кроме боли в горле?\n<пациент> Слабость сильная, голова болит, ломит все тело.\n<врач> Можете открыть рот и показать горло? Есть ли налет на миндалинах?\n<пациент> Да, там какие-то белые точки.\n<врач> Увеличились ли лимфоузлы на шее?\n<пациент> Да, с правой стороны болезненная шишка.\n<врач> Был ли контакт с больными?\n<пациент> На работе несколько человек болели.\n<пациент> Не объясняй их, просто напиши 3 самых вероятных потенциальных диагноза на русском\n<пациент> Не пиши пояснений к диагнозу в скобках, просто напиши самое подходящие название диагноза один раз\n</диалог>\nНе объясняй их, просто напиши 3 самых вероятных потенциальных диагноза обернув тегами\nКаждый ответ оберни в теги <diag_diag> и </diag_diag>"
  ],
  "outputs": [
    "<diag_diag>Ангина</diag_diag>\n<diag_diag>Тонзиллит</diag_diag>\n<diag_diag>Грипп</diag_diag>"
  ],
  "claims": [
    ["Ангина", "Тонзиллит", "Грипп"]
  ],
  "use_threshold": true
}'
```

Parameter ```use_threshold``` regulates the output type - either numerical confidence scores or thresholded 'low', 'medium' and 'high' scores.
